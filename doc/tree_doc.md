# Документация для tree.h

## Общее описание

Файл `tree.h` содержит реализацию структуры данных дерева для парсинга и хранения структурированных данных, похожих на JSON. Основное назначение - разбор строк с фигурными скобками и создание древовидной структуры данных.

## Основные компоненты

### Структура sTreeNode

Базовая структура узла дерева с тремя типами:

- `OBJECT` - объект, содержащий дочерние элементы (фигурные скобки `{...}`)
- `STRING` - строковое значение (GUID, имена, значения)
- `NUMBER` - числовое значение

#### Поля:
- `type` - тип узла
- `children` - вектор дочерних узлов (для OBJECT)
- `value` - строковое значение (для STRING и NUMBER)

#### Методы:
- `addChild()` - добавление дочернего узла
- `addString()` - добавление строкового узла
- `addNumber()` - добавление числового узла
- `print()` - вывод дерева с отступами
- `getTypeString()` - получение строкового представления типа
- `toString()` - преобразование в строку в формате, похожем на JSON

### Класс BracketParser

Парсер, который разбирает строку с фигурными скобками и создает дерево узлов.

#### Основные функции:
- `parse()` - разбор строки (поддерживает как `std::string`, так и `std::wstring`)
- `isValid()` - проверка валидности строки
- `getRoot()` - получение корневого узла
- `printTree()` - печать всего дерева
- `treeToString()` - преобразование дерева в строку

#### Особенности парсинга:
- Поддержка вложенных фигурных скобок
- Обработка строк в кавычках
- Распознавание GUID (36-символьные строки в формате xxxxxxxx-xxxx-xxxx-xxxxxxxxxxxx)
- Распознавание чисел
- Поддержка Unicode/UTF-8
- Обработка разделителей (запятые)

### Класс TreeNode

Альтернативная реализация узла дерева (в настоящее время не используется полностью, так как часть методов закомментирована).

## Использование

```cpp
// Создание парсера
BracketParser parser;

// Разбор строки
std::string input = "{ \"name\": \"value\", \"number\": 123 }";
if (parser.parse(input)) {
    // Получение корня дерева
    sTreeNode* root = parser.getRoot();
    
    // Вывод дерева
    parser.printTree();
    
    // Преобразование обратно в строку
    std::wstring result = parser.treeToString();
}
```

## Особенности реализации

- Использование `std::unique_ptr` для управления памятью
- Поддержка как ASCII, так и Unicode строк
- Обработка ошибок при парсинге
- Валидация UTF-8 символов
- Распознавание GUID формата
- Поддержка многоуровневой вложенности объектов

## Закомментированные функции

Некоторые функции в файле закомментированы:
- `findGuids()` - поиск всех GUID в дереве
- `findCyrillicStrings()` - поиск кириллических строк
- `TreeNode` деструктор и вспомогательные методы

Эти функции могут быть активированы при необходимости дополнительного функционала.
